# Reinforcement Learning Architectures in Drone Simulations

This is a dissertation for MSc Machine Learning in Royal Holloway, University of London. 

Submitted 1st September 2026

This readme complements Section 10 of the report

## Installation
- Download and install [uv](https://docs.astral.sh/uv/getting-started/installation/) for your OS
- Run `uv sync` to install python and all packages
- Run the commands given in section 10 of the report

## Hardware notes
- Use the run_one files to run one ablation at a time
- Task B requires a GPU, but can be set to cpu (need to change `device='cpu'` in the code)
